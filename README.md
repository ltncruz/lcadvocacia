# Luciano Cruz Advocacia

Site institucional desenvolvido para **Luciano Cruz Advocacia**, com foco em apresentação profissional, experiência responsiva, acessibilidade, contato rápido e presença digital voltada à atuação em Direito de Trânsito.

O projeto foi construído com **HTML, CSS e JavaScript puro**, sem frameworks, priorizando desempenho, organização do código, responsividade e facilidade de manutenção.
